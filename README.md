# Ember

IELTS practice website with listening, reading, writing, speaking, grammar, and spaced vocabulary review.

- 14 study days, 138 automatically checked questions, and 28 writing/speaking tasks.
- 84 vocabulary words with audio and 14 listening recordings.
- Normal and slow word playback, writing drafts, and speaking recordings.
- Warm, compact interface with Chinese instructions and English practice material.

## Use

Open the GitHub Pages website linked in this repository's About section. The site uses static HTML, CSS, and JavaScript; no build or API key is required. GitHub Pages publishes the `main` branch root, with `.nojekyll` disabling Jekyll processing.

The website is public. Progress, answers, drafts, and personal voice recordings are stored in the current browser, not in this repository. They are not synchronized between devices.

When changing websites, export a study backup from the old site's settings and import it into the new site. Voice recordings must be downloaded separately; the application does not currently import recording files.

Practice stories and listening recordings are original learning material. Audio uses synthetic English speech. Official IELTS practice resources are linked and labeled in the application. Writing checks and speaking self-review do not predict an IELTS score.
